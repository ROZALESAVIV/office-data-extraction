# Office Data Extraction System

## Overview

A system for extracting structured data from PDF documents and integrating with Odcanit API.

## Goals

* Upload PDF documents
* Extract relevant fields
* Allow user review
* Send structured data to Odcanit

## Tech Stack

* Frontend: React + TypeScript
* Backend: FastAPI (Python)
* Database: PostgreSQL (later)

## Current Stage

Sprint 1 – Frontend prototype (Upload + Review flow)
